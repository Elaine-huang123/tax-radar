📐 设计文档 · 规则说明

评分标尺、分级逻辑、类别与信息源映射规则

📗 P1 · 税务政策 — 规则与信息源

  • 收录：增值税 / 消费税 / 个税 / 企业所得税 / 出口退税等税收政策、申报与征管（以中国财税机关公告为主）。
  • 判级：按税务评分口径（≥20 为 A）；公司退税主体所在地政策优先关注（申报地口径，内部维护）。
  • 例外：平潭综合实验区等无公司主体的区域性政策不作重点（库内平潭条目已降级）。

📘 P2 · 海关清关 — 规则与信息源

  • 收录：中国海关 + 亚马逊站点国家（美国 / 欧盟 / 加拿大 / 墨西哥 / 日本）的进出口清关、关税、商品归类与反倾销。
  • 判级：A = 关税 / 清关强制合规重点（CBP、IOR、MRN/EORI、商品编号等）；与公司品线无关的单一品类（如无人机）最高 B。
  • 站点国家海关资讯由每日检索（WebSearch 兜底）覆盖，无独立信息源。
页内级P2 判级依据（评分仅作参考因子）
A 重点原 A 标识 / 评分≥20；或命中「关税 · 清关 · CBP · IOR · MRN · EORI · 商品编号」等强制合规且评分≥12（无人机等与司品线无关的单一品类除外，最高 B）
B 关注评分 10–19 且不满足 A；或与司品线无关但有影响的品类关税（如无人机 232 关税 21→B）
C 一般评分<10 或程序性 / 低影响（如聚甲醛进口税率继承 7 分、电子单证 0 分）

📙 P3 · 平台与合规 — 规则与信息源

  • 收录：平台规则（亚马逊 / 沃尔玛 / 美客多，含 沃尔玛美国线下商超动态）、CPSC/FCC 产品合规、上市公司披露与行业资讯。
  • 判级：A = 高影响合规且与公司品线（汽车工具 / 小家电）相关；无关品类（3C 周边召回等）最高 B。
  • 例外：eBay 平台公司暂不涉及，不作重点（库内 eBay 条目已降级）。
页内级P3 判级依据（评分仅作参考因子）
A 重点平台 / 监管「强制限期 · 批量召回 · 禁售 · 准入受限 · 账户核验」且评分≥10，并与公司品线（汽车工具 / 小家电）相关或全品类强制（如 FCC 扫地机器人、泛欧 FBA、香港验证；eBay 禁售因不涉 eBay 已降 B）
B 关注评分≥10 但不满足 A；3C 周边等司无关品类召回（如暖手宝 / 磁吸充电宝）；财报披露、物流动态
C 一般评分<10 或低影响（如小众厨具召回 Cuisinart 烧烤刷 7 分）

一、评分标尺（0-30 分）

按跨境电商关键词权重评分，核心维度及权重如下：

维度权重说明
税种命中0-8 分出口退税(8) > 关税/反倾销(7) > 增值税(5) > 消费税(5) > 其他(1)
影响国家0-6 分中国(6) > 美国(4) > 欧盟(3) > 东南亚(2) > 其他(1)
影响品线0-6 分电池(6) > 3C(5) > 跨境零售(4) > 全品线(4) > 出口业务(4) > 服装(3) > 其他(1)
发布机关级别0-5 分财政部+税务总局联合(5) > 财政部/税务总局单独(4) > 海关总署(4) > 商务部(3) > 其他(1)
时效与紧迫性0-3 分即刻生效(3) > 30天内(2) > 已征求意见(1) > 远期(0)
信息源权威度0-2 分官网原文(2) > 权威媒体转载(1) > 社区/公众号(0.5)

总分 = 各维度求和（上限 30 分）。影响国家维度：中国政策权重最高（国内税务/海关/退税变动直接影响所有出口卖家成本底线）。

二、分级逻辑

  • A级标识 = true → 直接定级 A（人工标记的重大政策）
  • 否则按评分阈值：score ≥ 20 → A · 10-19 → B · <10 → C

五、品线与关注口径（公司实际业务）

  • 公司关注品线：汽车工具类 + 小家电（如空气泵、应急电源、雪刷、万用表、钳表、小冰箱、制冰机、冰沙机等）。
  • P2/P3 的 A 级判定以与公司品线相关性为参考：与品线相关或全品类强制合规 → A（重点关注）；与公司无关的单一品类事件（如无人机、3C 周边召回）最高定级 B。
  • P1 税务仍按税务评分口径定级（中国/财税/税种权重优先）。品线词表在 JS 的 COMPANY_LINES / OFF_LINES 中维护。
